## Configuracion

Variables de entorno: `DJANGO_SECRET_KEY` (obligatoria), `DJANGO_ALLOWED_HOSTS` (separadas por coma), `DJANGO_DEBUG=1` solo en desarrollo.

Base de datos: copie `bascula.cnf.example` a `bascula.cnf` con credenciales propias, y defina `MYSQL_ROOT_PASSWORD` y `MYSQL_PASSWORD` para docker-compose.
